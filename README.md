# Obsidian Lattice — AI, Machine Learning & Blockchain 3D Portfolio

An interactive, scroll-choreographed 3D WebGL portfolio crafted in a deep obsidian monochrome palette accented with pure cyan (`#00FFFF`) telemetry details.

## Experience Chapters

1. **01 · Neural Summit** — A clean 4-layer 3D neural network core with traveling cyan signal impulses, housed inside a 3x3x3 modular obsidian cube lattice over sculpted terrain and hexagonal basalt columns.
2. **02 · Selected Systems** — Four faceted obsidian-glass crystal shards suspended in depth, each enclosing a distinct procedural AI/cryptography sculpture. Clicking any crystal opens an architectural case study overlay with an animated data-flow pipeline and tabular performance benchmarks.
3. **03 · Consensus Iris** — A vertical dive through a hexagonal basalt canyon and multi-axis machined gyroscope portal framed by hyper-velocity warp light streaks.
4. **04 · Network Pedestal** — A circuit-etched circular telemetry pedestal hosting a 20,000-particle GLSL curl-swirl sculpture morphing between geometric channel emblems (`Neural Core`, `GitHub`, `X / Twitter`, `Hugging Face`, `LinkedIn`).
